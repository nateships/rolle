---
title: Settings
description: General, Appearance, About, and Advanced settings.
---

| Tab | Setting | Meaning |
| --- | --- | --- |
| General | Default region | Pre-fills the region for new AWS sessions. `us-east-1` by default |
| General | Assume role duration | Requested STS `AssumeRole` duration in minutes. 60 by default |
| General | Terminal | Terminal app for **Open terminal**. Auto-detect by default |
| General | Keep running in the tray | Hide the window on close instead of quitting |
| Appearance | Theme | System, light, or dark |
| About | Updates | Check for updates, install, or turn off the six-hour check |
| Advanced | Verbose logging | Same as `ROLLE_DEBUG=1` |
| Advanced | Replay onboarding | Runs the onboarding flow again |
| Advanced | Reset | Removes every session, integration, secret, and cached credential |

Settings live in the workspace file and apply to the CLI too.
