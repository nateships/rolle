## Long-lived secrets stay in the keychain

Identity Center refresh tokens, Azure token caches, and IAM user access keys live in the OS keychain (macOS Keychain, Windows Credential Manager, Secret Service on Linux) under the service name `rolle`. Large tokens are split into chunks to fit platform limits.

## Short-lived credentials are cached, then expire

Started sessions cache their temporary credentials in the cache directory (`~/.cache/rolle/credentials`, or the platform cache location) with owner-only permissions. `credential_process` reads that cache. Entries carry their expiry and are refreshed or removed by the app.

## AWS config is written with care

Rolle writes only profiles it owns, marked with a `rolle_session` key. It refuses to touch a section that holds `aws_access_key_id` or other credential keys. A plain `[default]` section that only sets region or output is taken over and restored on stop.

## No telemetry

The app and the CLI collect nothing. Network traffic goes to the cloud providers you sign in to, and to `github.com` for the update manifest when the update check is on. No analytics, no crash reporting, no usage data.

## Enterprise networks

TLS is verified against the OS trust store: the macOS Keychain, Windows certificate store, or the Linux system bundle. A corporate root installed there, as TLS inspection products require, works with no Rolle configuration. For a root that is not in the OS store, point **Settings → Advanced → Extra CA bundle** at a PEM file. **HTTPS proxy** routes every request through one proxy when the app cannot see your shell's `HTTPS_PROXY`. Both apply to the CLI and the app, including the AWS SDK calls.

## Signed updates

Release manifests are signed with an Ed25519 key. The desktop app verifies the signature before it installs an update. macOS builds are signed with a Developer ID certificate and notarized.

## Reset

`rolle reset` and **Settings → Advanced → Reset** remove the workspace, every keychain entry, the credential cache, and the AWS profiles Rolle wrote.
