title: Projects
description: Reuse gcloud credentials and get a session per project.
---

A Google Cloud integration reuses the Application Default Credentials of `gcloud`. Every project you can reach is a session.

```sh
gcloud auth application-default login
rolle integration add gcp                 # alias defaults to "gcp"
rolle integration sync gcp
rolle start my-project
eval "$(rolle env my-project)"
```

The desktop app runs the `gcloud` sign-in. When `gcloud` is not installed, it shows the command to copy. Install the SDK with Homebrew, the official installer, or [mise](https://mise.jdx.dev) (`mise use -g gcloud`).

To act as a service account, add an [impersonation session](/gcp/impersonation).
