## Go gopher

Go gopher by Renee French, licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). Adapted for Rolle with stacked credential cards and an r cutout.

This credit applies to `readme-gopher.png`. Retain the creator credit, license link and adaptation notice when using the mascot. The desktop icons contain only the credential stack.

Source and attribution: [The Go Gopher](https://go.dev/blog/gopher), [original character image](https://go.dev/doc/gopher/frontpage.png).

## Wordmark font

The custom wordmark uses MuseoModerno Bold outlines by Omnibus-Type, with an r copied from Rolle’s icon geometry. The bundled MuseoModerno variable font is unmodified.

Source: [Omnibus-Type/MuseoModerno](https://github.com/Omnibus-Type/MuseoModerno). Its SIL Open Font License 1.1 is included at [fonts/OFL-MuseoModerno.txt](fonts/OFL-MuseoModerno.txt). Preserve that license when redistributing the bundled font.

These artwork and font licenses are separate from the repository’s software license.
