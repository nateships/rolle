## Wordmark font

The custom wordmark uses MuseoModerno Bold outlines by Omnibus-Type, with an r copied from Rolle's icon geometry. The bundled MuseoModerno variable font is unmodified. Its source is https://github.com/Omnibus-Type/MuseoModerno and its SIL Open Font License 1.1 is included at fonts/OFL-MuseoModerno.txt. This credit is separate from the README gopher artwork.
